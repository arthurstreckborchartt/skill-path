# Skill Path

Quero criar uma plataforma web responsiva chamada provisoriamente de “Pathly”.

A ideia central do produto é:

“Aprenda o que realmente importa para ganhar mais.”

A plataforma não será uma simples plataforma de cursos.

O usuário informa:

- quanto ganha atualmente

- quanto deseja ganhar

- profissão atual

- experiência

- habilidades que já possui

- tecnologias/ferramentas que conhece

- interesses

- área em que gostaria de trabalhar

- nível de escolaridade

- horas livres disponíveis por semana

- se deseja emprego, estágio, freelancer, trabalho remoto ou empreender

- prazo aproximado para atingir seu objetivo

A plataforma deve analisar a situação atual da pessoa e criar uma rota personalizada entre:

ONDE ELA ESTÁ HOJE

e

ONDE ELA QUER CHEGAR.

Exemplo:

Hoje:

R$ 2.600/mês

Objetivo:

R$ 8.000/mês

A plataforma poderá gerar uma rota como:

1. Aprender Python + APIs

2. Criar projeto real

3. Publicar projeto no GitHub

4. Melhorar portfólio

5. Aprender banco de dados

6. Criar projeto mais avançado

7. Preparar currículo

8. Se candidatar a determinadas vagas

9. Fazer freelas paralelamente

10. Evoluir para uma determinada especialização

Cada etapa deve ter:

- objetivo

- prazo estimado

- dificuldade

- impacto esperado

- habilidades adquiridas

- projetos recomendados

- recursos para estudar

- checklist

- progresso

- recompensa/XP

IMPORTANTE:

Nesta primeira etapa quero que você foque principalmente na estrutura geral do produto, UX/UI e identidade visual.

DESIGN

Quero um produto extremamente moderno, premium e tecnológico.

Referências conceituais:

- Linear

- Notion

- Duolingo

- Arc

- Stripe

- Apple

- ChatGPT

- interfaces modernas de startups SaaS

NÃO copie essas empresas.

Use apenas como referência de qualidade.

O produto precisa ter personalidade própria.

Quero evitar aparência de:

- dashboard empresarial genérico

- template pronto

- site corporativo antigo

- excesso de cards

- excesso de bordas

- interface cheia de informação

Quero uma experiência:

- extremamente intuitiva

- minimalista

- divertida

- fluida

- jovem

- elegante

- limpa

- viciante de usar

- agradável tanto no computador quanto no celular

IDENTIDADE VISUAL

Crie uma identidade visual própria para o produto.

Use:

- fundos claros ou dark sofisticados, escolha o que funcionar melhor

- cores de destaque vibrantes mas elegantes

- gradientes muito sutis

- tipografia moderna

- ícones minimalistas

- cantos arredondados

- sombras extremamente suaves

- bastante respiro visual

- hierarquia visual excelente

Nada deve parecer infantil.

A gamificação deve parecer premium, semelhante a aplicativos modernos de produtividade.

ANIMAÇÕES

Adicionar microinterações sofisticadas:

- hover suave

- cards reagindo levemente ao mouse

- transições entre páginas

- animação de progresso

- números animados

- barras preenchendo suavemente

- XP aparecendo ao concluir tarefas

- pequenas celebrações

- elementos surgindo com fade/slide suave

- skeleton loading

- feedback instantâneo ao clicar

Não exagerar.

Tudo deve parecer natural e extremamente fluido.

RESPONSIVIDADE

A experiência mobile deve ser pensada separadamente.

Não quero simplesmente o desktop comprimido.

Desktop:

- sidebar elegante

- bastante espaço

- informações visuais

- dashboard completo

Mobile:

- navegação inferior

- telas mais focadas

- botões fáceis de pressionar

- conteúdo apresentado progressivamente

- excelente experiência com uma mão
